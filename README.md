# python-student-project
Student Record Management System 🎓

About the Project

The Student Record Management System is a beginner-friendly Python project developed to manage student academic records. It allows users to enter student details and marks, calculate the average score, determine the student's grade, and check whether the student has passed or failed.
This project demonstrates the use of Object-Oriented Programming (OOP) in Python.

Features

- Enter student name and admission number.
- Input marks for three subjects.
- Calculate the average marks.
- Automatically assign a grade based on the average.
- Determine whether a student has passed or failed.
-
-  Technologies Used
-  Python 3
- Object-Oriented Programming (OOP)

Grading System

Average Marks| Grade
70–100| A
60–69| B
50–59| C
40–49| D
Below 40| E
Pass mark: An average of 40 or above.

How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. python main.py

Note: If your Python file has a different name, replace "main.py" with your actual filename.
